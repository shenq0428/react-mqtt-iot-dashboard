# React MQTT IoT Dashboard

A custom IoT dashboard built with React, Node.js, and MQTT to replace Grafana for real-time device monitoring and control.

## 🚀 Features

* Real-time data visualization
* Device control (ON/OFF)
* MQTT publish/subscribe
* Custom dashboard UI

## 🧱 Tech Stack

* Frontend: React (Vite)
* Backend: Node.js (Express)
* Messaging: MQTT

## 📡 Architecture

React → Node.js → MQTT Broker → Device
